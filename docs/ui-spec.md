# UI Contract

## Current status

The current screen is a neutral temporary foundation placeholder. It is not the operational shell.

## Planned console

The desktop layout is rail, map, and a conditional inspection drawer; the map remains dominant. Tablet keeps the map dominant with a compact rail and dialog-based inspection. There is no bottom bar and no driver-facing interaction.

The future topbar contains only the provisional product name, an `EN` language control offering English and Español without flags, Help, and Account. It excludes LIVE, WebMCP, agent, simulation, and stage-plan decorations.

The visual language is professional and operational: no gradients, glassmorphism, giant cards, sparkle icons, excessive rounding, decorative metrics, chat, or surveillance framing. The rail categories are all, resting, needs attention, critical, weather affected, driving/rest risk, and road/restriction issues.

All visible and fallback copy will resolve through typed locale catalogs. A vehicle drawer appears only after selection; future Fleet Edit Mode is unavailable.
